# GROW — نسخه نمایشی GitHub Pages

این پوشه یک نسخه **استاتیک و مستقل** از پروژه GROW است که برای GitHub Pages آماده شده است.

## ویژگی‌ها
- داشبورد و شاخص‌های خلاصه
- ساخت، ویرایش و حذف هدف‌ها
- برنامه روزانه و تیک‌زدن کارهای انجام‌شده
- چک‌لیست عادت‌ها
- مرور روزانه با امتیاز حال و یادداشت
- پیشنهادهای از پیش‌تعریف‌شده و نمای پیشرفت
- تم روشن/تیره
- ذخیره‌سازی داده‌ها با `localStorage`

## محدودیت‌های مهم
GitHub Pages فقط فایل‌های استاتیک را میزبانی می‌کند؛ بنابراین این نسخه PHP، MySQL، ورود/ثبت‌نام، API یا پیشنهاد هوش مصنوعی واقعی ندارد. داده‌ها روی همان مرورگر و همان دستگاه ذخیره می‌شوند. برای استفاده چندکاربره و امن، بک‌اند باید جداگانه روی یک سرویس سازگار میزبانی شود.

## انتشار روی GitHub Pages
1. فایل ZIP را استخراج کن.
2. وارد مخزن GitHub پروژه `grow` شو.
3. فایل‌های نسخه دمو را در ریشه مخزن قرار بده؛ به‌طوری‌که `index.html` مستقیماً در ریشه باشد.
4. تغییرات را Commit و Push کن.
5. در مخزن به **Settings → Pages** برو.
6. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کن.
7. Branch را `main` و پوشه را `/(root)` انتخاب کن و Save بزن.
8. پس از اتمام Deploy، آدرس سایت در همان صفحه نمایش داده می‌شود.

> اگر قصد داری نسخه PHP اصلی را هم نگه داری، آن را در شاخه/مخزن جداگانه نگه دار؛ GitHub Pages فایل‌های PHP را اجرا نمی‌کند.

## اجرای محلی
روی `index.html` دوبار کلیک کن. برای بهترین نتیجه می‌توانی از افزونه Live Server در VS Code هم استفاده کنی.

## بازنشانی
از منوی کناری «بازگردانی داده‌های نمونه» را بزن. این کار فقط داده‌های ذخیره‌شده این دمو در مرورگر فعلی را پاک و نمونه‌ها را بازسازی می‌کند.
