# GROW — نسخه نمایشی GitHub Pages

این پوشه یک نسخه **استاتیک و مستقل** از پروژه GROW است که برای GitHub Pages آماده شده است.

## ویژگی‌ها
- داشبورد و شاخص‌های خلاصه
- ساخت، ویرایش و حذف هدف‌ها
- برنامه روزانه و تیک‌زدن کارهای انجام‌شده
- چک‌لیست عادت‌ها
- مرور روزانه با امتیاز حال و یادداشت
- پیشنهادهای از پیش‌تعریف‌شده و نمای پیشرفت
- تم روشن/تیره
- ذخیره‌سازی داده‌ها با `localStorage`
